# Company Detail Page - Quick Start Guide

## 🚀 How to Access

1. **Login** to your account
2. **Go to Dashboard** or **Company List**
3. **Click any company card**
4. **OR click "Prepare Now"** button
5. Page loads at: `http://localhost:5174/company/{id}`

---

## 📋 What You'll See

### 6 Complete Tabs

```
┌──────────────────────────────────────────────────────┐
│ 📖 Overview | 🎯 Process | 📄 Questions |            │
│ 🏆 Strategy | ▶️ Resources | 💡 Tips                 │
└──────────────────────────────────────────────────────┘
```

---

## 🎮 How to Use Each Tab

### 1️⃣ Overview Tab

**What's Here:**
- Company description
- Industry information
- Difficulty level
- Hiring frequency
- Total questions count
- Quick stats (rounds, questions, weeks)

**Use It To:**
- Understand the company
- Know what to expect
- See preparation scope

---

### 2️⃣ Interview Process Tab

**What's Here:**
- Step-by-step interview rounds
- Duration for each round
- Detailed descriptions
- **"How to Crack" tips** for each round

**Rounds Included:**
1. Aptitude Round
2. Coding Round
3. Technical Interview
4. HR Interview

**Use It To:**
- Understand the interview flow
- Know what each round covers
- Get specific tips for each round

---

### 3️⃣ Questions Tab ⭐

**What's Here:**
- All practice questions
- Filter by type (HR/Technical/Coding/Aptitude)
- Expandable answers
- YouTube video links
- **"Mark as Done" button**

**How to Use:**

1. **Filter Questions:**
   - Click "All", "HR", "Technical", "Coding", or "Aptitude"
   - Grid shows only that type

2. **View Answer:**
   - Click the ▼ arrow
   - Answer expands below question
   - Read detailed explanation

3. **Watch Video:**
   - Click "Watch Video Explanation"
   - Opens YouTube in new tab

4. **Mark as Done:**
   - Click "Mark Done" button
   - Button changes to "✓ Done"
   - Card gets green border
   - Progress bar updates

5. **Track Progress:**
   - See progress bar at top
   - Shows X/Y questions completed
   - Percentage displayed

---

### 4️⃣ Strategy Tab ⭐

**What's Here:**
- Week-by-week preparation plan
- Different duration based on difficulty:
  - **Easy**: 4 weeks
  - **Medium**: 6 weeks
  - **Hard**: 8 weeks
- Daily hour recommendations
- Specific tasks for each week

**Example Plan (Amazon - Hard):**

```
Week 1: Advanced Aptitude (3 hrs/day)
  ✓ Complex quantitative problems
  ✓ Advanced logical puzzles
  ✓ Critical reasoning practice
  ✓ Speed mathematics techniques

Week 2: Data Structures Deep Dive (5 hrs/day)
  ✓ Advanced trees (BST, AVL, Segment Trees)
  ✓ Graph algorithms
  ✓ Heaps and Priority Queues
  ✓ Hash tables

... (8 weeks total)
```

**How to Use:**

1. **Follow the Plan:**
   - Start with Week 1
   - Complete all tasks
   - Move to next week

2. **Mark Complete:**
   - Click week header
   - Checkmark appears
   - Card turns green
   - Visual progress

3. **Time Management:**
   - See hours/day for each week
   - Plan your schedule
   - Stay consistent

---

### 5️⃣ Resources Tab

- **YouTube Videos** - Interview experiences, tutorials
- **Articles & Guides** - How-to guides, question lists
- **Courses** - Udemy, Educative, free platforms

**How to Use:**

1. **Click Resource Card:**
   - See title, type, duration/price
   - Click action button (Watch/Read/Enroll/Practice)

2. **Open in New Tab:**

---

### 6️⃣ Tips Tab

**What's Here:**
- **Do's** (10 tips) - What you should do
- **Don'ts** (10 tips) - What to avoid
- **Common Mistakes** (10 items) - Pitfalls
- **Success Tips** (10 tips) - Best practices

**Examples:**

✅ **Do's:**
- Research the company thoroughly
- Practice coding daily (2-3 problems)
- Revise core CS fundamentals
- Prepare project explanations

❌ **Don'ts:**
- Don't fake knowledge
- Don't ignore HR questions
- Don't cram the night before
- Don't be late

⚠️ **Common Mistakes:**
- Not researching company culture
- Focusing only on coding
- Poor communication
- Not practicing with time limits

🌟 **Success Tips:**
- Start 4-8 weeks early
- Create structured study plan
- Practice with peers
- Learn from every interview

**How to Use:**

1. **Read All Tips:**
   - Go through each category
   - Understand the reasoning

2. **Apply Immediately:**
   - Start with Do's
   - Avoid Don'ts
   - Learn from mistakes

3. **Bookmark Important Ones:**
   - Screenshot key tips
   - Add to your notes
   - Review before interview

## 💡 Pro Tips

3. **Check Strategy** - Plan your preparation
4. **Browse Resources** - Gather study materials

2. **Afternoon**: Practice questions

2. **Check off weeks** when done
3. **Watch progress bar** grow

## 🎯 Sample Workflow

### Example: Preparing for Amazon

**Day 1:**
1. Open Amazon company page
2. Read Overview tab

5. Read tips (all 4 categories)

1. Take mock interviews
2. Revise all concepts
3. Review tips again
4. Check progress (aim for 80%+ questions)
5. Feel confident!

## 🔧 Troubleshooting

### No Data Showing?
1. Check backend is running
2. Verify company has data
3. Refresh the page
4. Check browser console

### Progress Not Saving?
- Progress is currently **local only** (session-based)
- Refreshing page resets progress
- Future update will add persistent storage

### Links Not Working?
- All external links open in new tab
- Check internet connection
- Some links are search queries (YouTube)
